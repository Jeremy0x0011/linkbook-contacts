# Linkbook 智能通讯录

面向“极限编程”作业的 Web 通讯录。项目已经覆盖作业的必做功能，并额外完成了搜索、公司分组、联系人多方式快捷复制和响应式页面。

在线演示：<https://jeremy0x0011.github.io/linkbook-contacts/>

源码仓库：<https://github.com/Jeremy0x0011/linkbook-contacts>

## 已实现功能

| 作业要求 | 实现方式 |
| --- | --- |
| 页面样式 | 桌面端三栏布局、移动端响应式列表、统一设计系统 |
| 收藏联系人 | 联系人卡片和详情页均可收藏/取消收藏，可进入“我的收藏”筛选 |
| 多种联系方式 | 每位联系人可无限添加电话、邮箱、社交媒体、地址和其他联系方式 |
| Excel 导出 | 每位联系人占一行，每类资料独立成列，支持全部联系方式 |
| Excel 导入 | 读取标准 Excel，自动过滤空行和重复联系人 |
| 数据保存 | 浏览器 `localStorage` 自动持久化 |
| 扩展能力 | 增删改查、关键词搜索、公司筛选、快捷复制、下载导入模板 |

## 启动项目

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端中显示的地址，默认通常为 `http://localhost:5173`。

生产构建与本地预览：

```bash
npm run build
npm run preview
```

运行自动化测试：

```bash
npm test
```

## Excel 文件格式

页面顶部可以下载标准模板。主要表头如下：

| 姓名 | 公司 | 职位 | 是否收藏 | 备注 | 联系方式1-类型 | 联系方式1-内容 | 联系方式2-类型 | 联系方式2-内容 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 张三 | 示例公司 | 产品经理 | 是 | 示例备注 | 电话 | 13800000000 | 邮箱 | name@example.com |

“联系方式N-类型”和“联系方式N-内容”可以继续向后扩展。导入时也兼容“电话”“邮箱”“社交媒体”“地址”等直接表头。

## 代码结构

```text
src/
├── App.jsx              # 页面、状态和主要交互
├── lib/
│   ├── contacts.js      # 联系人模型与数据处理
│   └── excel.js         # Excel 导入、导出和模板
└── styles.css           # 页面样式与响应式规则
```

## 云端部署

`npm run build` 后，将 `dist/` 目录部署到任意静态站点服务即可，例如 Nginx、华为云 OBS、阿里云 OSS 或 Vercel。只打开 `localhost` 不算原作业要求的云端部署，必须提供公网可访问地址。
